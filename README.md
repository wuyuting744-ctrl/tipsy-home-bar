# 微调 · Tipsy Club

居家调酒的交互 HTML 原型。双击 `index.html` 即可打开，无需安装依赖。

## GitHub Pages

仓库关联后，GitHub Pages 使用 `main` 分支根目录发布。
本地修改并预览确认后，提交修改并运行 `git push`，网站将自动重新部署。
`index.html`、`styles.css` 和 `app.js` 必须保存在同一目录；`.nojekyll` 用于直接发布静态文件。

## 可体验的功能

- 调一杯：按家中材料筛选可做配方、缺一两种材料的配方、无酒精饮品；支持搜索和分步制作。
- 我的酒单：收藏经典配方、创建个人配方；酒柜入口和朋友点单入口都在这里。
- 酒柜：勾选家中已有配料，实时更新推荐。
- 今晚点单：主人选择可供应菜单，朋友填写昵称并通过本机菜单下单，主人处理制作队列。
- 经典酒谱：10 款经典鸡尾酒的居家配方、历史介绍和延伸阅读，以及 1 款无酒精饮品。
- 账号：本地注册、登录、退出和一键演示账号；每个账号独立保存酒柜、收藏、配方及订单。注册会继承当前体验模式数据。

## 原型边界

所有数据保存在当前浏览器的 localStorage 中，不会跨设备同步。登录只模拟账号体验，不具有后端认证能力；请勿输入真实密码。演示密码使用 SHA-256 摘要存储，但这不构成生产环境的密码存储方案。

朋友点单目前采用本机菜单。二维码、多设备实时订单、库存数量与自动扣料、邮件验证与密码找回需在正式版接入后端。

页面适配桌面与手机；装饰插画为本地 SVG，Google Fonts 加载失败时使用系统字体。

## 验证

`verify.cjs` 使用本机 Edge 和 Playwright 验证酒柜、分步调制、自创配方、登录注册、错误密码、点单队列、数据持久化、搜索及手机宽度，并生成预览截图。它需要环境中提供 Playwright，验证使用独立临时浏览器，不影响正常使用的数据。
